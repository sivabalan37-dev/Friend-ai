## About

Thala is a voice assistant for Android that talks with you in **Tamil** and **English**, in a friendly young female voice. Ask it to open apps, set timers, add calendar events and take care of other everyday tasks, all **without any external AI API**.

## Features

- 🗣️ **Tamil + English** – speaks and understands both languages
- 👧 **Friendly young female voice**
- 📱 **Open apps** by voice
- ⏱️ **Set timers**
- 📅 **Create calendar events**
- ✅ **Everyday tasks** – and more
- 🔌 **No external AI API** – no API keys, no third-party AI service
- 📦 **Built on GitHub** – the APK is produced right here with GitHub Actions

## Download & Install

### Get the APK

- **From Releases:** download the latest APK from the [Releases](https://github.com/sivabalan37-dev/Thala-ai/releases) page.
- **From GitHub Actions:** open the **Actions** tab, run the build workflow (or push a commit to trigger it), then download the APK from **Artifacts**. It arrives zipped, so unzip it first.

### Install

1. Open the APK on your phone.
2. If Android blocks the install, allow **Install unknown apps** for your browser or file manager when prompted.
3. Open Thala, allow the permissions it asks for, and start talking.

## Usage

Speak to Thala naturally in Tamil or English. A few examples:

| English | தமிழ் | What happens |
|---|---|---|
| "Open WhatsApp" | "வாட்ஸ்அப் திற" | Opens the app |
| "Set a timer for 5 minutes" | "5 நிமிடங்களுக்கு டைமர் வை" | Starts a 5-minute timer |
| "Add a meeting tomorrow at 4 PM" | "நாளை மாலை 4 மணிக்கு கேலண்டரில் மீட்டிங் சேர்" | Creates a calendar event |
